Privacy Policy

Last updated: 2026/10/11

This page describes the privacy policy of Unity's Workshop.

Google Drive Data

Unity's Workshop accesses image files in Google Drive that users explicitly select through the Google Picker interface and through the JSON upload interface. The accessed data includes:

  • The contents of the image files
  • The filename and MIME type
  • Drive file ID and optional resource key
  • A temporary OAuth access token

How Data Is Used

That data is used locally in the browser to render cards. OAuth tokens are used to authorize access to Drive files. File IDs and resource keys are used to locate the authorized files. Image content is used to render cards. The operators of the website do not receive or store any user data.

Storage, Retention, and Sharing

The operators of the website do not receive or store any Google drive data, access tokens or image contents. OAuth tokens remain only in browser page memory, and not browser storage. They are cleared when reloading or leaving the page, and also expire after a short period.

Google API Limited Use

Unity’s Workshop’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. It only accesses the data necessary to provide its functionality and does not share it with unauthorized parties. Users may share their own exported JSON data at their discretion.

Changes to This Privacy Policy

Changes to this privacy policy will be posted on this page, and the updated policy will take effect immediately upon posting.
